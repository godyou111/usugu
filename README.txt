하수구 (가로) - GitHub Pages 업로드용

배포 방법
1. GitHub 저장소를 엽니다.
2. Add file -> Upload files를 선택합니다.
3. 이 압축파일을 푼 뒤 index.html을 저장소 최상위(root)에 업로드합니다.
4. Settings -> Pages에서 배포 소스를 설정합니다.
   - Deploy from a branch
   - Branch: main
   - Folder: / (root)
5. Save 후 잠시 기다리면 사이트 주소가 생성됩니다.

참고
- 게임 이미지/데이터는 HTML 안에 포함되어 있습니다.
- Three.js는 CDN에서 불러오므로 게임 실행 시 인터넷 연결이 필요합니다.
- 저장소 최상위에 index.html이라는 이름으로 올려야 GitHub Pages 첫 화면으로 열립니다.
